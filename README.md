# 💰 FinancesPro — Application de Gestion de Budgets

FinancesPro est une plateforme web moderne de gestion des finances personnelles permettant de centraliser vos revenus, dépenses, comptes financiers, budgets prévisionnels et objectifs d'épargne.

---

## ✨ Fonctionnalités Principales

- 🔐 **Authentification & Sécurité** : Inscription/Connexion, 2FA (TOTP), rôles & autorisations, journal d'audit des actions.
- 💳 **Gestion Multi-Comptes** : Banque, Mobile Money (MVola, Orange Money), Espèces, Épargne.
- 💸 **Transactions & Transferts** : Suivi des revenus, dépenses et virement inter-comptes (sans pollution des stats).
- 📊 **Budgets & Alertes Progressives** : Alertes visuelles à 50%, 75%, 90% et 100% de dépassement.
- 🎯 **Objectifs d'Épargne** : Calcul automatique de l'épargne mensuelle nécessaire et suivi de progression %.
- 📅 **Abonnements & Échéances** : Calculateur de coûts mensuels/annuels et rappels des factures à venir.
- 🤖 **Analyse & IA Financière** : Détection d'anomalies, prédictions de fin de mois et assistant en langage naturel.
- 💱 **Multi-Devises** : Prise en charge du Ariary (MGA), Euro (€), Dollar ($) et Livre (£).
- 👥 **Espaces Partagés** : Collaboration familiale/équipe avec gestion des rôles (Admin, Membre, Lecture seule).
- 🌐 **API REST Sanctum** : Endpoints prêts pour l'application mobile (Flutter).

---

## 🛠️ Stack Technique

- **Backend** : Laravel 12 (PHP 8.4)
- **Frontend** : React 19, Inertia.js, TypeScript, Tailwind CSS v4
- **Graphiques** : Recharts
- **Base de Données** : SQLite (Dev) / PostgreSQL (Prod)
- **Sécurité API** : Laravel Sanctum
